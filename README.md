🐿️ Eurobot 2026 - Robot Software StackWelcome to the official Eurobot 2026 team repository.This project contains the embedded intelligence, simulation, and strategy tools for our robot. It features a hybrid architecture using ROS 2 Humble for robotic control and Gazebo Ignition for physical simulation.🏁 Quick StartPrerequisitesOS: Ubuntu 22.04 LTS (Jammy Jellyfish)Framework: ROS 2 Humble HawksbillSimulator: Gazebo Ignition (Fortress or Garden recommended)📥 InstallationCreate a ROS 2 workspace:mkdir -p ~/eurobot_ws/src
cd ~/eurobot_ws/src
Clone this repository:git clone <REPO_URL> .
git checkout origin/feat_model_3  # We recommend the active feature branch
Install dependencies:cd ~/eurobot_ws
sudo apt update
rosdep update
rosdep install --from-paths src --ignore-src -r -y
Note: Ensure python3-pip is installed for Python dependencies (scipy, sympy).Build the project:colcon build --symlink-install
🎮 Running the SimulationTo launch the robot in the virtual arena with Rviz and Gazebo:Source the environment:source install/setup.bash
Launch the main launchfile:ros2 launch mam_eurobot_2026 arena.launch.py
This opens: Gazebo (World), Rviz (Sensor Viz), and Control Nodes.🤖 Running on Real RobotTo start the software stack without the 3D simulation:ros2 launch mam_eurobot_2026 robot_nodes.launch.py
