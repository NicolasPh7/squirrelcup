🐿️ Eurobot 2026 - Stack Logicielle RobotBienvenue sur le dépôt officiel de l'équipe pour Eurobot 2026.Ce projet héberge l'intelligence embarquée, la simulation et les outils de stratégie du robot. L'architecture est hybride, couplant ROS 2 Humble pour le contrôle temps-réel et Gazebo Ignition pour la simulation physique.🏁 Démarrage RapidePrérequisOS : Ubuntu 22.04 LTS (Jammy Jellyfish)Middleware : ROS 2 Humble HawksbillSimulateur : Gazebo Ignition (Fortress ou Garden recommandé)📥 InstallationPréparer l'espace de travail ROS 2 :mkdir -p ~/eurobot_ws/src
cd ~/eurobot_ws/src
Cloner le dépôt :git clone <URL_DU_REPO> .
git checkout origin/feat_model_3  # Branche recommandée (Robot V3)
Installer les dépendances :cd ~/eurobot_ws
sudo apt update
rosdep update
rosdep install --from-paths src --ignore-src -r -y
Note : Assurez-vous d'avoir python3-pip pour les libs mathématiques (scipy, sympy).Compiler le projet :colcon build --symlink-install
🎮 Lancer la Simulation (Gazebo + Rviz)Pour visualiser le robot dans l'arène virtuelle et tester la logique :source install/setup.bash
ros2 launch mam_eurobot_2026 arena.launch.py
Ce que ça lance :Gazebo Ignition (Monde & Physique)ros_gz_bridge (Pont ROS <-> Ignition)Rviz (Visualisation Capteurs/TF)Nœuds de contrôle (Commander, Vision, Odométrie)🤖 Lancer sur le Robot RéelPour démarrer uniquement la stack logicielle (sans la simu 3D) sur le PC embarqué :ros2 launch mam_eurobot_2026 robot_nodes.launch.py
🏗️ Architecture du ProjetLe dépôt s'articule autour du métapaquet mam_eurobot_2026.DossierDescription & Rôlemam_eurobot_2026/Cœur du système. Contient les launchfiles, configs et scripts.├── launch/Scripts de démarrage (arena.launch.py, robot_nodes.launch.py).├── config/Paramètres YAML (Marqueurs ArUco, PID, Config Simu).├── mam_eurobot_2026/Logique Haut-Niveau (Python). Cinématique, Machine à états, Commander.├── src/Performance (C++). Vision, Odométrie, Drivers bas niveau.robot_v3/Description URDF/Xacro du robot complet (Base + Bras 5 axes).nut_identifier_msgs/Messages ROS custom (ex: NutPositionArray).eurobot2026-strategy-sim/Sandbox C++. Simulateur 2D léger (SFML) pour le prototypage rapide (Hors-ROS).🧩 Modules Techniques1. Vision & Perception (src/)Analyse d'image et extraction de features.Détection Éléments (nut_identifier2.cpp) : Segmentation HSV pour localiser les écrous/objets. Projection 3D via modèle sténopé.Localisation (aruco_localization.cpp) : Recalage absolu sur la table via balises ArUco fixes. Support multi-caméras (embarquée + zénithale).2. Contrôle Bras Manipulateur 5 DoFSitué dans mam_eurobot_2026/arm_kinematics/.Cinématique Inverse (IK) : Approche hybride. Résolution symbolique (SymPy) prioritaire, fallback sur optimisation numérique (SciPy) en cas de singularité.Driver : Le nœud arm_commander.py interface les requêtes de stratégie avec les contrôleurs matériels.3. Navigation & OdométrieOdométrie (inertial_odometry.cpp) : Intégration temporelle des encodeurs (méthode Runge-Kutta 2) pour un suivi précis de la pose du robot (odom -> base_link).🛠️ Développement & ContributionGestion des Branches (Git Flow)origin/feat_model_3 (Active) : 🌟 Contient le Robot V3 complet et la vision intégrée.origin/dev : Branche de développement stable.main : Code legacy et simulateur stratégie 2D.TestsPour vérifier que tout fonctionne avant un push :# Lancer les tests d'intégration ROS 2
